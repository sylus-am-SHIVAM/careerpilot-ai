# CareerPilot AI 🚀

An AI-powered career guidance platform that helps students discover career paths, analyze resumes, identify skill gaps, generate personalized learning roadmaps, and receive AI-powered mentorship using Large Language Models (LLMs) and Retrieval-Augmented Generation (RAG).

---

## ✨ Vision

CareerPilot AI aims to become a personal AI mentor that guides students from confusion to career clarity through personalized recommendations and intelligent assistance.

---

## 🎯 Planned Features

- 🤖 AI Career Mentor
- 📄 Resume Analysis
- 📈 Skill Gap Detection
- 🛣️ Personalized Learning Roadmaps
- 🎯 Career Recommendations
- 🏫 College & Course Suggestions
- 💼 Internship Recommendations
- 🎤 Mock Interview Preparation
- 📊 Progress Tracking Dashboard
