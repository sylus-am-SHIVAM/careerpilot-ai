# Technology & Engineering Careers

## Software Engineer
Software engineers design, build, test and maintain applications, websites and backend systems.
Core skills: one strong programming language (Python, Java, JavaScript or C++), data structures and algorithms, Git, databases (SQL), REST APIs, basic system design, testing and debugging.
Learning path: start with programming fundamentals and problem solving, then learn DSA, then build full projects (a web app with login, database and deployment). Contribute to open source and practise on platforms like LeetCode or Codeforces for interviews.
Free resources: CS50 (Harvard), freeCodeCamp, The Odin Project, NPTEL programming courses, official documentation.
Portfolio ideas: full-stack web app, REST API with authentication, a CLI tool, an open-source contribution.
Entry routes in India: B.Tech/BE in CS or IT, BCA/MCA, or any degree plus a strong project portfolio. Campus placements, off-campus applications and internships are common entry points.

## Data Scientist
Data scientists turn data into insights and predictive models that support decisions.
Core skills: Python (pandas, NumPy, scikit-learn), statistics and probability, SQL, data visualisation, machine learning basics, communicating findings.
Learning path: Python and SQL first, then statistics, then exploratory data analysis, then classical machine learning, then end-to-end projects with real datasets.
Free resources: Kaggle Learn, Google's Machine Learning Crash Course, StatQuest (YouTube), NPTEL data science courses.
Portfolio ideas: Kaggle notebooks, a dashboard on public Indian data (data.gov.in), a prediction model with clear write-up.

## Machine Learning Engineer
ML engineers build, train, deploy and monitor machine learning and AI models in production.
Core skills: Python, linear algebra and calculus basics, machine learning, deep learning (PyTorch or TensorFlow), working with LLM APIs, MLOps basics (Docker, model serving, monitoring).
Learning path: become comfortable with data science basics, then deep learning, then deploy a model behind an API, then learn about LLMs, embeddings and retrieval-augmented generation (RAG).
Free resources: fast.ai, Andrew Ng's courses (Coursera audit), Hugging Face course, PyTorch tutorials.
Portfolio ideas: an image or text classifier served with FastAPI, a RAG chatbot over your own documents, a fine-tuned small model.

## Cybersecurity Analyst
Cybersecurity analysts protect systems and networks from attacks and investigate security incidents.
Core skills: networking (TCP/IP, DNS, HTTP), Linux, operating system internals, scripting (Python or Bash), web security basics (OWASP Top 10), security tools and log analysis.
Learning path: networking and Linux fundamentals, then security concepts, then hands-on labs and capture-the-flag (CTF) challenges, then a recognised entry-level certification if budget allows.
Free resources: TryHackMe free rooms, OverTheWire, PortSwigger Web Security Academy, OWASP documentation.
Portfolio ideas: CTF write-ups, a home lab, a vulnerability report on an intentionally vulnerable app.

## Frontend and UI Developer
Frontend developers build the parts of applications users see and interact with.
Core skills: HTML, CSS, JavaScript, a framework such as React or Next.js, responsive design, accessibility, calling APIs.
Learning path: HTML/CSS/JS fundamentals, then build small static sites, then learn React, then build a full project that consumes a real API.
Free resources: MDN Web Docs, freeCodeCamp, The Odin Project, official React and Next.js docs.
Portfolio ideas: personal portfolio site, clones of popular UIs, a dashboard that consumes a public API.
