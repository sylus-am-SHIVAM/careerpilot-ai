# CareerPilot AI — Frontend

Next.js 16 + Tailwind CSS client for the CareerPilot AI backend.

```bash
npm install
npm run dev        # http://localhost:3000
```

The API base URL defaults to `http://127.0.0.1:8000/api/v1`; override it with `NEXT_PUBLIC_API_URL` in `.env.local`.
See the root [README](../README.md) for full setup.
